ZenOven workflow automation

Private automation for authorized workflows

n8n-znv is a private, self-hosted workflow-automation service operated by ZenOven. It connects Google Sheets and Google Drive to automate document, content, and file-processing tasks for authorized users.

Access is limited. This is not a public consumer application. Only users explicitly authorized by the operator may use the service or connect a Google Account.

How the application works

1. Connect

An authorized user connects a Google Account using OAuth.

2. Automate

The workflow reads or updates selected spreadsheet rows and works with files required for that workflow.

3. Control

The user or operator can disconnect the credential, revoke access, or delete workflow data.

Google user data

The application requests only the Google Sheets and Google Drive access needed by configured workflows. Google user data is used to perform those workflows; it is not sold or used for advertising. See the Privacy Policy for the specific access, processing, storage, sharing, retention, and deletion rules.
