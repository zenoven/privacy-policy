# n8n-znv public information and privacy policy

This repository contains the public application information, privacy policy,
and terms for **n8n-znv**, a private workflow-automation service operated by
ZenOven.

The site is designed to be published at:

- App homepage: `https://www.zenoven.com/n8n-znv/`
- Privacy policy: `https://www.zenoven.com/n8n-znv/privacy/`
- Terms of service: `https://www.zenoven.com/n8n-znv/terms/`

These pages are intentionally static and contain no analytics, cookies,
external fonts, or client-side JavaScript.

## Google OAuth scope

The policy describes the Google API access used by the current automation:

- Google Sheets read/write access
- Google Drive access to files used or created by the automation
- Google Drive file metadata access

It also explains the self-hosted n8n storage boundary, optional workflow
processors, retention and deletion, revocation, and Google API Services User
Data Policy Limited Use compliance.

## Deployment

Publish the files in this repository as static files under the same path on the
verified `zenoven.com` domain. The app homepage must remain publicly available
without login and must link to the privacy policy.
